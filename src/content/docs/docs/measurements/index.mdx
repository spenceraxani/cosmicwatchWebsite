These are the measurements from *The Example Measurements*, the third v3X manual. The first sixteen have been done with CosmicWatch detectors. The last four are open ideas: if you try one, we would love to hear how it went.

Most need two detectors in [coincidence mode](/docs/coincidence-mode/). Start with the [full-sky rate](/docs/measurements/full-sky-rate/), since every other measurement builds on it.
