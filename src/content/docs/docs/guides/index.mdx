The v3X manuals live as PDFs in the [GitHub repository](https://github.com/spenceraxani/CosmicWatch-Desktop-Muon-Detector-v3X). These pages are the same text and figures, split by chapter so you can link to a section, search it, and read it on a phone.

**How these pages stay current.** Each page knows which version of its PDF it was made from. When you open a page, it asks GitHub whether the PDF has changed since then. If it has, the page tells you and links the newer PDF. A scheduled job checks the repository every day and regenerates the pages when a PDF changes, so the notice only lasts until the next sync.

The text and figures are pulled from the PDFs automatically. Equations and tables are shown as images cut from the PDF. If something reads oddly, the PDF is the reference.
